# HTML Forms and Styling Lab

Solutions for the SoftUni "HTML and CSS" lab on forms and styling, written in plain HTML5 and CSS3.

**Author:** Keipher Ross
**Course:** CIT 232 , T.A. Marryshow Community College

## Exercises

| Folder | Description |
|--------|-------------|
| `P01_LoginFormImages` | Login form with `<img>` icons positioned over the inputs |
| `P02_LoginForm-font-awesome` | Same login form, using Font Awesome icons |
| `P03_LoginForm-BGImages` | Same login form, using CSS `background-image` for the icons |
| `P04_ContactForm` | Contact form with name, email, message, subject and a Send button |
| `P05_ArrangingTheWidths` | Form with fieldset and legend where all fields have equal widths |

## How to view

Download or clone the repository, open a folder, and open the `.html` file in your browser.

Exercise 2 loads Font Awesome and Google Fonts from the internet, so it needs a connection to display correctly.
